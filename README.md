# User List

A simple and responsive **User List Web Application** built using **HTML, CSS, and JavaScript**. The project fetches user information from the JSONPlaceholder API and displays it in attractive cards.

## 📌 About the Project

The User List project demonstrates how to retrieve data from an external API using JavaScript's `fetch()` method and dynamically display the received information on a webpage.

Each user card displays:

* User Name
* Email Address
* Phone Number
* City
* Company Name

The layout is responsive and automatically adjusts for smaller screen sizes.

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**
* **JSONPlaceholder API**

## ⚙️ How It Works

1. HTML creates the basic webpage structure.
2. JavaScript uses the `fetch()` method to retrieve user data.
3. The API response is converted into JSON.
4. JavaScript loops through the user data.
5. User cards are created dynamically.
6. CSS provides responsive styling and hover effects.

## 🚀 How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. User information will load automatically from the API.
